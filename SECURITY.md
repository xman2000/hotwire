# Security

Hotwire runs on game servers that belong to other people, so a security problem in it matters to every server it is
installed on.

## Reporting a problem

E-mail **security@afkpanel.com**. Please do not open a public issue for it.

Say what you found, the version it is in (`hotwire check` prints the plugin's; each launcher prints its own when it
starts) and how to reproduce it. A person reads every report. AFKPanel's
[security.txt](https://afkpanel.com/.well-known/security.txt) lists the same address.

## Versions

Fixes go into the newest release. Releases are published on
[GitHub](https://github.com/xman2000/hotwire/releases), and afkpanel.com's downloads always point at the newest one.
